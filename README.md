## Some tools I have created (or currently working on)
- Pega-Utils [P-Utils](https://p-utils.netlify.app/)
> `p-Utils` Explore Pega applications, visualize class hierarchies, analyze case flows, compare environments, and monitor system health; all through interactive graph visualizations. Free to use online with all features included.
- T-V [T-V](https://t-v.netlify.app/)
> `T-V` is a local-first web application designed for analyzing Pega Tracer XML files directly in the browser. Users can load trace files and explore execution events entirely on their own machine, ensuring privacy and fast performance even for large exports
